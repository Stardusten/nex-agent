## Hindsight builtin memory plugin

- 新增 `builtin:memory.hindsight` 插件本体：
  - `mcpServers` 通过 streamable HTTP 连接 Hindsight MCP。
  - 暴露 `hindsight__recall`、`hindsight__retain`、`hindsight__mental_model`、`hindsight__operation_status`。
  - `prompt.build.before` hook 调 recall 注入长期记忆。
  - `conversation.turn.finished` hook enqueue retain task，写入带 session/channel/workspace provenance 的内容。
  - 初始化 `memory/hindsight/status.json` 与 `memory/hindsight/exports/`。
  - 新增 `hindsight-memory` skill，明确 Hindsight 是 derived memory，不替代本地 session/file/ControlPlane 原始证据。
- Hindsight 作为 builtin plugin 打包，但默认配置仍把 `builtin:memory.hindsight` 放在 disabled 中，避免未安装本地 Hindsight MCP 时 runtime reload 主动连接 `localhost:8888`。
  - 用户显式 enable 后会继承默认 `mcp_url` / `bank_id` / 空 `authorization_header`；需要鉴权时直接在对应 plugin config 里填写 header。
- 顺手修复两个通用底座细节：
  - streamable HTTP MCP 空 header 会被丢弃，支持本地无鉴权 Hindsight 与配置化 Authorization header 共存。
  - `PluginWorkspaceFiles` 的 `kind: "dir"` 创建路径正确处理 `FileSystem.authorize/3` 的 `{:ok, info}`。
  - ToolRegistry 的 error summary 对非 string error struct 使用 `inspect/2`，避免 transport error 观测时崩溃。
